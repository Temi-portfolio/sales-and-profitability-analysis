# sales-and-profitability-analysis

## Tools Used 
-Microsift Excel
-Power BI

## Project Overview
This project analyzes  the sales and profitability performance of pharmacies across Europe.
It explores trends across regions and countries, profit margins and companies revenue using interactive dashboards.

## What I Learned 
How to clean messy data in Power Query.
How to use DAX formula to create calculations, measures, calculated colums and tables inside Power BI.
How to visualize insights through interactive dashboards in Power BI
